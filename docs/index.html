High-Dimensional Sparse Precision Matrix Estimation

MARS

Given p variables and n samples (p ≫ n), MARS estimates a sparse precision matrix Ω = Σ−¹ under the l1-penalized D-trace loss. Its sparsity pattern reveals the conditional-dependence graph among variables. R and Python implementations powered by a highly efficient adaptive sieving + semismooth Newton augmented Lagrangian (AS–SSNAL–PCG) algorithm.
View on GitHub JMLR Paper

01Precision Matrix = Conditional Dependence = Graph

MARS estimates the precision matrix (the inverse covariance matrix): its entries encode the conditional dependence between two variables given all the others.

Precision matrix

Ω = Σ−¹

The inverse of the covariance matrix Σ. Diagonal entries relate to partial variances; off-diagonal entries relate to conditional dependence.

Conditional dependence

Ωij = 0 ⇔ i ⊥ j | others

In a Gaussian graphical model, Ωij = 0 iff variables i and j are conditionally independent given all other variables.

Sparse graph

edge ⇔ Ωij ≠ 0

The sparsity pattern defines a graph: nodes = variables, edges = conditional dependence. The l1 penalty keeps the estimate sparse when p ≫ n.

02Model & Algorithm

Solves the l1-penalized D-trace loss by semismooth Newton augmented Lagrangian combined with adaptive sieving technique.
minΩ∈S⊃p;   ½ ‖Ω A‖F² − ⟨Ω, I⟩ + λ ‖Ω‖1,off

A is built from the centered sample matrix via thin SVD (A = U diag(s)/√(n−1)); ‖Ω‖1,off = Σi≠j|Ωij| penalizes off-diagonal entries to induce a sparse graph; λ controls sparsity. The full p×p Gram matrix is never formed.

Adaptive sieving (AS)

At each ALM iteration, screens the subproblem first: candidate non-zero edges are gathered from residuals, keeping the active set far smaller than p².

SSN (SSNAL)

Semismooth Newton then solves the screened active-set subproblem inside the augmented Lagrangian framework with second-order convergence.

Inner PCG

Preconditioned conjugate gradient solves the Newton systems; the gap < tol stopping rule makes optimality verifiable.

03Usage

R and Python, same algorithm, same solution path. Full installation, parameter reference and examples below (mirrors the package README).
# 1) installation: needs a C++ toolchain (Rtools on Windows, Xcode CLT on
#    macOS, g++ on Linux) plus Rcpp / RcppArmadillo / Matrix:
install.packages(c("Rcpp", "RcppArmadillo", "Matrix"))

#    from GitHub:
# library(devtools); devtools::install_github("QianLI-QL-XA/MARS")
#    or locally, from the package source (where DESCRIPTION lives):
install.packages(".", repos = NULL, type = "source")

# 2) minimal example: p = 3000, n = 50 synthetic data
library(MARS)
set.seed(1)
X <- matrix(runif(3000 * 50), 3000, 50)
sol <- MARS(X, stopmethod = "bigs",
            Lambdapath = seq(1, 0.5, -0.01), printmain = TRUE)
str(sol)          # Omegapath / Lambdapath / timepath

# 3) the nonzero pattern of Omega is the graph:
#    Omega[i,j] != 0 <=> i, j conditionally dependent
Omega <- as.matrix(sol$Omegapath[[1]])

MARS() returns a list with Omegapath (estimated sparse precision matrices, one per lambda, each a dsCMatrix from package Matrix), Lambdapath (the tuning parameters actually used) and timepath (wall-clock seconds per lambda).

The MARS() function

MARS(X, Lambdapath, stopmethod = c("bigs", "fix"), fixnumber = 1L,
     maxiter = 100L, maxlambdacheck = TRUE, printmain = FALSE,
     printsub = FALSE, stoptol = 1e-4, sigma = 1.0)

Full parameter reference: MARS README on GitHub.

Real-data example (prostate gene expression)

library(MARS)
prost <- read.csv("prostmat.csv", header = FALSE)   # 6033 x 102
X1 <- as.matrix(prost[, 1:50])        # control subjects (n = 50)
X2 <- as.matrix(prost[, 51:102])      # cancer subjects (n = 52)

sol1 <- MARS(X1, Lambdapath = c(0.5, 0.4, 0.3, 0.25),
             stopmethod = "fix", maxiter = 10, stoptol = 1e-4)
sol2 <- MARS(X2, Lambdapath = c(0.5, 0.4, 0.3, 0.25),
             stopmethod = "fix", maxiter = 10, stoptol = 1e-4)

# sparsity pattern = gene network: Omega[i,j] != 0 means genes i, j are
# conditionally dependent given all other genes
Omega <- as.matrix(sol1$Omegapath[[4]])

# 1) installation: needs Python 3.8+; NumPy core, optional Numba JIT
#    acceleration (jit extra) — no MKL required:
pip install -e "./MARS_python[jit]"

# 2) solve a lambda path: p = 3000, n = 50
import numpy as np
from mars import mars_path, maxLambda

rng = np.random.default_rng(0)
X = rng.standard_normal((3000, 50))
lam = 0.95 * maxLambda(X)          # data-dependent max lambda
Omegapath, Lambdapath, timepath = mars_path(
    X, np.array([lam]), stoptol=1e-6, maxiter=10, stopmethod="fix")

Omega = Omegapath[0]               # 3000x3000 symmetric; nonzero pattern = graph

The Python implementation is numerically equivalent to the R version (verified iteration-by-iteration) and is roughly 3–4× faster than the pure-NumPy baseline when the Numba JIT kernels are enabled. The public API is mars_path(X, Lambdapath, stoptol, maxiter, stopmethod, ...); maxLambda(X) returns the data-dependent max-lambda.

Performance notes

The R package links against the system BLAS/LAPACK. Replacing the default Reference BLAS with a multi-threaded BLAS (e.g. Intel MKL) can speed up the matrix-heavy parts 5–6×. On Windows this means using an MKL-enabled build of R (e.g. Microsoft R Open) or replacing Rblas.dll / Rlapack.dll in R-<version>/bin/x64 with the MKL versions; make sure the MKL runtime mkl_rt.2.dll is available in the same directory so that compiled packages can load. The adaptive sieving strategy keeps the active set small in the high/medium-lambda regime, so memory stays low even when p is large.
