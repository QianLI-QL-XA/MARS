01精度矩阵 = 条件相关 = 图

MARS 估计的对象是精度矩阵（协方差矩阵的逆），它刻画的是两个变量在给定其余所有变量后的条件相关关系。

精度矩阵

Ω = Σ⁻¹

协方差矩阵 Σ 的逆。它的对角元与偏方差有关，非对角元与条件相关有关。

条件相关

Ωij = 0 ⟺ i ⊥ j | 其余变量

对高斯图模型：Ωij = 0 当且仅当变量 i 与 j 在给定其余变量时条件独立。

稀疏图

边 = Ωij ≠ 0

非零模式定义一张图：节点 = 变量，边 = 条件相关。l1 惩罚保证 p ≫ n 下估计稀疏。

ij=0）

02模型与算法

求解带 l1 惩罚的 D-trace 损失，组合三种数值技术以应对 p ≫ n。
minΩ∈Sᵖ   ½ ‖Ω A‖F² − ⟨Ω, I⟩ + λ ‖Ω‖1,off

A 由样本中心化 + thin SVD 得到（A = U diag(s)/√(n−1)）； ‖Ω‖1,off = Σi≠j|Ωij| 惩罚非对角元，诱导稀疏图； λ 控制稀疏度。算法全程不构造 p×p 的 Gram 矩阵。

STEP 1

自适应筛选 AS

从残差中增量筛出潜在非零边，保持活跃集远小于 p²，显著降低每次子问题规模。

STEP 2

半光滑牛顿 SSNAL

增广拉格朗日 + 半光滑牛顿求解活跃集上的子问题，二阶收敛速度。

STEP 3

内层 PCG

牛顿方程的预条件共轭梯度求解；gap < tol 停机判据保证解的最优性可验证。

03安装与快速上手

R 与 Python 双实现，同一算法、同一解路径。完整参数说明见《MARS 使用说明》。
# 安装（需 Rcpp / RcppArmadillo / Matrix + C++ 工具链）
install.packages(c("Rcpp", "RcppArmadillo", "Matrix"))
install.packages(".", repos = NULL, type = "source")

# 求解一条 λ 路径：p = 3000, n = 50 的合成数据
library(MARS)
set.seed(1)
X <- matrix(runif(3000 * 50), 3000, 50)
sol <- MARS(X, stopmethod = "bigs",
            Lambdapath = seq(1, 0.5, -0.01), printmain = TRUE)
str(sol)          # Omegapath / Lambdapath / timepath

# 返回的 Ω 稀疏非零模式即图：Ω[i,j] ≠ 0 ⟺ 变量 i、j 条件相关
Omega <- as.matrix(sol$Omegapath[[1]])

# 安装（Numba 可选，缺省自动回退纯 NumPy）
pip install -e "./MARS_python[jit]"

# 求解：p = 3000, n = 50
import numpy as np
from mars import mars_path, maxLambda

rng = np.random.default_rng(0)
X = rng.standard_normal((3000, 50))
lam = 0.95 * maxLambda(X)          # 数据依赖 max-λ
Omegapath, Lambdapath, timepath = mars_path(
    X, np.array([lam]), stoptol=1e-4, maxiter=10, stopmethod="fix")

Omega = Omegapath[0]               # 3000×3000 对称矩阵，非零模式即图
